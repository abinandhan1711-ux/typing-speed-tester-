# ⌨️ Typing Speed Tester

A simple and interactive Typing Speed Tester built using HTML, CSS, and JavaScript. This application helps users measure their typing speed (Words Per Minute) and accuracy in real time.

## ✨ Features

- Real-time typing speed calculation (WPM)
- Accuracy tracking
- 60-second countdown timer
- Restart test functionality

## 📊 How It Works

1. Read the displayed sentence.
2. Start typing in the text area.
3. The timer starts automatically.
4. The application calculates:
   - Words Per Minute (WPM)
   - Typing Accuracy (%)
5. After 60 seconds, the test ends automatically.
6. Click **Restart** to try again.
